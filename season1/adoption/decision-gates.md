# Adoption decision gates

1. Confirm canonical upstream, publication and exact revision; reject unverified claims.
2. Review code license, dataset license, redistribution and commercial-use restrictions separately.
3. Reproduce at least one upstream baseline in isolated environment; capture command, version, seed, hashes and logs.
4. Map tasks to existing challenge IDs and test dimensions (language, speech, cache, communication, tool mutation).
5. Demonstrate an independent oracle or identify evaluator limitations.
6. Keep adapters outside core, optional and pinned; check supply-chain risks.
7. Compare at least two independent systems on the same public contract before asserting interoperability.
8. Publish decision: method-only / adapter / dataset / rejected / pending, with dated evidence.

No stage may upgrade self-attestation to independently observed effect.
